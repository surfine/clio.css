clio.css

A CSS library for classic Mac OS interfaces: System 6, System 7, Mac OS 8.5’s withdrawn Drawing Board theme and Mac OS 8/9 Platinum. Windows, menus, buttons, check boxes, pop-up menus, scroll bars and dialogs, drawn with CSS and small SVGs. Every value is traced to measured pixels or marked as inferred. No JavaScript, no screenshots or Apple fonts. MIT.

Get started

npm install clio.css
<link rel="stylesheet" href="https://unpkg.com/clio.css@0.10.0/dist/clio.css">

clio.css draws System 6 by default. Put data-era="system7", data-era="drawingboard" or data-era="platinum" on <html>, or on any element, to switch everything inside it to that era. clio.system6.css, clio.system7.css, clio.drawingboard.css and clio.platinum.css are single-era builds. Every rule uses :where() or a single class, so your own CSS always wins, and every value is a --clio-* custom property.

Coming from system.css? Its markup works unchanged: .window, .title-bar with button.close and button.resize, .details-bar, .window-pane, .btn, .btn-default, .standard-dialog, .modal-dialog, .alert-box, .field-row and role="menu-bar" menus.

Window

A document window: frame, title bar with close and zoom boxes (plus the WindowShade box in Platinum), an optional details bar and a scrolling pane. System 7 adds colour to the frame and title bar.

Accessibility
Give each box an aria-label (Close, Zoom, Collapse). The title is a real heading; pick the level that fits your page (h1 for a full-screen app window). Buttons keep a visible focus ring. On touch screens each box gets a 45px hit area while its art stays 11px.

Menu bar and menus

The menu bar across the top of the screen and its pull-down menus: items, keyboard shortcuts, check marks, separators, disabled items and submenus.

<ul class="menu-bar" role="menubar" aria-label="Menu bar">
  <li role="none" class="open">
    <button role="menuitem" aria-haspopup="true" aria-expanded="true">File</button>
    <ul class="menu" role="menu">
      <li role="none"><button role="menuitem">New Folder <kbd>⌘N</kbd></button></li>

      <li role="none"><button role="menuitem" aria-disabled="true">Print</button></li>

      <li role="none"><button role="menuitemcheckbox" aria-checked="true">Show Clipboard</button></li>
    </ul>
  </li>
  <li role="none"><button role="menuitem" aria-haspopup="true" aria-expanded="false">Edit</button></li>
  <li role="none"><button role="menuitem" aria-haspopup="true" aria-expanded="false">View</button></li>

Accessibility
Use role=menubar, role=menu and role=menuitem with aria-haspopup and aria-expanded on titles. A menu opens while its title has aria-expanded=true, while its <li> has the class open, or while focus is inside it, so it works from the keyboard without script. Arrow-key movement between items is up to your script.

Also accepts: system.css markup (ul[role=menu-bar], [role=menu-item], li.divider).

Evidence policy

The values come from AI System 6, a writing desktop that recreates these eras and measures them against real screens: System 6.0.8, System 7.5.3 and Mac OS 8.5 (with the 8.5b6 Drawing Board theme) in the Infinite Mac emulator, and Mac OS 9.0 in Infinite Mac and from GUIdebook captures. Each value carries one of four labels:

  • Measured read from real pixels of the era.
  • Inferred reasoned from documentation or behaviour, not yet measured.
  • Adapted a deliberate change for the web: touch sizes, keyboard focus, contrast.
  • Third-party art or a font from a named, licensed project.

clio.css ships no screenshots, icons, logos or Apple fonts; screenshots stay evidence only. Small control parts for System 7, Mac OS 9 and Drawing Board (boxes, arrows, check boxes, tab ends) are redrawn pixel for pixel by a script, from measured pixels or the theme’s own resources, and labelled in the evidence; large textures are not reproduced. The fonts are ChicagoFLF (public domain) and Asap (SIL Open Font License). The full table is in EVIDENCE.md.
